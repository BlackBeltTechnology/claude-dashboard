<task type="auto">
  <name>Task 1: Fix chronological ordering by merging nodes and subagents into a single timestamp-sorted list</name>
  <files>client/src/components/TreeView.tsx</files>
  <action>
In TreeView.tsx, the `renderNode` callback handles Session children in two separate loops:
1. `node.nodes.forEach(...)` — processes messages, tools, skills, subagents from the `nodes` array
2. `node.subagents.forEach(...)` — appends subagent Session objects at the end

This causes subagents to always appear at the bottom regardless of when they occurred chronologically. Fix this by:

1. After processing `node.nodes` into `processedNodes` and grouping them via `groupConsecutiveToolCalls`, merge the session's `subagents` array into the result list based on timestamp.

2. Create a combined list of `{ item: AnyNode | ToolGroup | Session, timestamp: number }` entries from both `groupedNodes` and `node.subagents`.

3. For grouped tool nodes (ToolGroup), use the group's `timestamp` field (which comes from the first node in the group).

4. For subagent Session objects, use `subagent.createdAt` as the timestamp.

5. Sort the combined list by timestamp ascending (earliest first).

6. Iterate the sorted combined list and call `renderNode` for each item. This replaces both the `groupedNodes.forEach` and `node.subagents.forEach` loops.

The result: all session children (messages, tool groups, skills, subagent sessions) appear in correct chronological order as a single interleaved timeline.

Important: Do NOT change how tool-group expansion, subagent expansion, or click handlers work. Only change the ordering of children within a session.
  </action>

Run `npm run build` from project root — TypeScript compiles without errors. Visually confirm in browser that tree view shows events in timestamp order (subagents interleaved with tool calls at the correct chronological position, not appended at the end).
  </verify>
  <done>

  </done>
</task>

<task type="auto">
  <name>Task 2: Reduce nesting depth by starting session children at depth 0 and reducing indentation per level</name>
  <files>client/src/components/TreeView.tsx, client/src/components/TreeNode.tsx</files>
  <action>
The tree view currently nests all session children at depth 1+ with 16px indentation per level and 20px margin for child containers. This creates excessive horizontal nesting that wastes space and reduces readability for timeline-style viewing.

Make these changes:

**In TreeView.tsx:**
1. When rendering session children in `renderNode`, pass `depth` instead of `depth + 1` for the session's direct children. This makes session content start at the same level as the session header, effectively treating the session as a header row rather than a nesting parent. The session node itself still renders at its original depth.

**In TreeNode.tsx:**
2. Reduce the `childrenContainer` marginLeft from `20px` to `12px`. This tightens the visual nesting so that when items ARE nested (e.g., tool groups expanding to show individual tools), the indentation is more compact.

3. Reduce the per-depth paddingLeft multiplier in the `rowStyle` calculation from `16px` to `12px`. Change the formula from `${8 + depth * 16}px` to `${8 + depth * 12}px`. This compresses each nesting level to use less horizontal space.

The combined effect: session children start at the leftmost position (depth 0) with only 12px indentation per further nesting level, creating a flatter, more timeline-like appearance while still showing hierarchy for expanded tool groups and subagent internals.
  </action>
