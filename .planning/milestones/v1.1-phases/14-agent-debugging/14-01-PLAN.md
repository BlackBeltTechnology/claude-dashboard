  <action>
    **SubagentNode.tsx changes:**

    1. Add a new optional callback prop `onToolCallClick` to SubagentNodeData:
       ```typescript
       onToolCallClick?: (toolCallId: string) => void;
       ```

    2. In the tool calls list rendering (the `{showTools && data.toolCalls && ...}` block), make each tool call row clickable. When a row is clicked:
       - Call `e.stopPropagation()` to prevent the parent node click from firing
       - Call `data.onToolCallClick?.(tool.id)` to notify the parent graph of which tool was clicked

    3. Add a hover style to tool call rows to indicate clickability. Use a slightly lighter background on hover (e.g., `rgba(255, 255, 255, 0.1)`) and `cursor: 'pointer'`.

    **GraphView.tsx changes:**

    1. In the `onNodeClick` handler's `subagent` branch, the current code builds `detailData` with toolCalls and subagentNodes. This already works for clicking the subagent node itself to open its detail panel.

    2. The challenge: React Flow's `onNodeClick` fires when clicking anywhere on the node. To handle tool call clicks specifically, we need to use a different mechanism. Since React Flow nodes are rendered components, we can pass a callback via node data.

    3. In the `convertSessionToGraph` call's result processing, or more practically: after `createLayoutedGraph` returns nodes, we need to attach `onToolCallClick` callbacks to subagent nodes. However, since `createLayoutedGraph` is a pure layout function, we should NOT modify it.

    4. Instead, use a `useEffect` or `useMemo` to post-process the layouted nodes and attach the callback. After `createLayoutedGraph` returns:
       - Map over nodes where `node.type === 'subagent'`
       - Add `data.onToolCallClick = (toolCallId: string) => { ... }` that:
         a. Finds the subagent session from sessions (using `node.data.agentId`)
         b. Finds the tool node by ID within that subagent's nodes
         c. Calls `setSelectedNodeData(toolNode)` to open the tool detail panel

    5. Important: The `onToolCallClick` callback must be created with `useCallback` or within a `useMemo` that has access to `sessions` and `setSelectedNodeData`. Attach it during the existing `useMemo` that computes layouted nodes, or create a new `useMemo` that enriches nodes after layout.

    6. To prevent the subagent's own detail panel from opening when a tool call row is clicked, the `e.stopPropagation()` in SubagentNode will prevent the event from bubbling to React Flow's `onNodeClick`. If `stopPropagation` on the tool row doesn't prevent `onNodeClick` (since React Flow may use its own event system), consider adding a state flag or short-circuit: if a tool call was just clicked, skip the `onNodeClick` handler for that subagent. A simpler approach: use a ref like `const toolCallClickedRef = useRef(false)` in GraphView, set it true from the callback, and check+reset it in `onNodeClick`.
  </action>
