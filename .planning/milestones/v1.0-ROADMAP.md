# Roadmap: Claude Session Dashboard

## Overview

This roadmap delivers tool call grouping and human-readable session identification for the Claude Session Dashboard. We start by implementing client-side grouping infrastructure to collapse consecutive tool calls by type, then add side panel drill-down for inspecting grouped calls in detail, and finally extract working directory names from session files for recognizable session labels.
