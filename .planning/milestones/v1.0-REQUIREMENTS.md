# Requirements: Claude Session Dashboard

**Defined:** 2026-02-06
**Core Value:** Make Claude Code agent activity visible and navigable at a glance

## v1 Requirements

### Session Identification

- [x] **SESS-01**: Sessions display working directory name instead of UUID in sidebar list
- [x] **SESS-02**: Sessions with same directory name disambiguated with #1, #2 suffix
- [x] **SESS-03**: Session nodes in graph/tree views show working directory name

### Tool Call Grouping

- [x] **TOOL-01**: Consecutive tool calls of same type grouped into single node (e.g. "Bash (12)")
- [x] **TOOL-02**: Grouped tool calls display in both tree and graph views
- [x] **TOOL-03**: Clicking a tool group opens right side panel with list of individual calls
- [x] **TOOL-04**: Clicking an individual call in side panel shows command/content detail
- [x] **TOOL-05**: Side panel closeable via close button or clicking outside

## v2 Requirements

### Enhanced Grouping

- **EGRP-01**: Inline group summaries showing success/failure counts
- **EGRP-02**: Group preview on hover (tooltip with first N items)
- **EGRP-03**: Quick filter from group context menu

### Enhanced Session Identification

- **ESID-01**: Full working directory path shown on hover tooltip

## Out of Scope

| Feature | Reason |
|---------|--------|
| Nested grouping (groups within groups) | Over-complicates UI, harder to navigate |
| Group by parent message instead of type | Creates many tiny groups, doesn't reduce noise |
| Auto-expand all groups on load | Performance killer with large sessions |
| Real-time group animations | Distracting when groups constantly update |
| Custom session labels/aliases | Unnecessary — directory names are sufficient |
| Keyboard navigation for groups | Power user feature, defer to v2+ |
