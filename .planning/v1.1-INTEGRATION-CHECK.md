### Complete E2E Flow Verification

#### Flow 1: Navigation (Directory → Session → Tree Panel → Sync)

**Status:** ✅ COMPLETE

**Steps:**
1. User lands on DirectoryOverview (navigationView === 'directory' in App.tsx)
2. User clicks session node → DirectoryOverview.handleNodeClick calls enterSession(sessionId, cwd)
3. enterSession atomically updates: navigationView='session-timeline', selectedSessionId, currentDirectoryCwd, viewMode='graph', treePanelOpen=false
4. App.tsx routes to GraphView based on navigationView='session-timeline'
5. Layout.tsx conditionally renders TreePanel when navigationView='session-timeline'
6. User clicks tree toggle button → Toolbar calls toggleTreePanel() → treePanelOpen=true
7. TreePanel slides in with CSS transform animation
8. User clicks tree node → TreeView calls setFocusedNode(createNodeId(sessionId, node.id))
9. GraphView.GraphFocusHandler reacts to focusedNodeId change → calls fitView with focused node
10. Graph pans/zooms to center the node with 300ms animation

**Verification:** All connections present, no breaks

#### Flow 2: Timeline Rendering (Server → Client → Graph → Detail)

**Status:** ✅ COMPLETE

**Steps:**
1. Server reads JSONL entries → buildNodes() creates UserPromptNode and ClearMarkerNode
2. UserPromptNode gets promptText, commandName, commandMetadata from extractReadablePrompt and XML parsing
3. ClearMarkerNode gets clearIndex from sequential counter
4. Server emits nodes via WebSocket session-update message
5. Client handleWebSocketMessage updates sessionStore.sessions
6. GraphView calls createLayoutedGraph with updated sessions
7. graphLayout collects user-prompt and clear-marker nodes into timeline array
8. Timeline sorted chronologically by timestamp
9. Timeline processed: user-prompt → UserPromptNode React Flow node, clear-marker → ClearMarkerNode React Flow node
10. GraphView registers node types and renders
11. User clicks node → onNodeClick calls setSelectedNodeData
12. NodeDetail renders renderUserPromptContent or renderClearMarkerContent with full data

**Verification:** Full data flow from server to UI, all steps connected

#### Flow 3: Agent Debugging (Click Tool → Detail Panel)

**Status:** ✅ COMPLETE

**Steps:**
1. GraphView enrichedNodes useMemo processes layoutedNodes
2. For each subagent node, attaches onToolCallClick callback
3. Callback searches sessions for subagent by agentId
4. SubagentNode renders tool calls list with onClick handlers
5. Tool row onClick calls e.stopPropagation() then data.onToolCallClick(tool.id)
6. Callback finds tool node in subagent session by matching tool.id
7. Callback calls setSelectedNodeData(toolNode)
8. NodeDetail opens and renders renderToolContent with tool input/output
9. For subagent nodes clicked directly: NodeDetail renders renderSubagentContent
10. renderSubagentContent shows ExpandableSection for Request (node.prompt) and Response (node.summary)
11. No ToolCallsList in subagent panel (removed per AGNT-02)

**Verification:** Clickable tool calls work, agent panel is clean, full click-to-detail flow intact

#### Flow 4: Tree View Integration (Chronological Order + Request/Response)

**Status:** ✅ COMPLETE

**Steps:**
1. TreeView.buildSessionTimeline filters session.nodes (excludes user messages, empty assistants, subagent metadata)
2. groupConsecutiveToolCalls groups tools into ToolGroup entries
3. Timeline items array built from grouped nodes
4. Subagents added to items with timestamp=subagent.createdAt
5. items.sort((a, b) => a.timestamp - b.timestamp) → chronological order
6. hiddenNodeTypes and nodeTypeFilters applied
7. For subagent sessions (node.id.length < 20):
   - Synthetic MessageNode created with role='user', content=firstUserPrompt (request)
   - Timeline items rendered in middle
   - Synthetic MessageNode created with role='assistant', content=summary (response)
8. TreeNode renders with depth * 12px indentation (reduced from 16px)
9. Children container uses marginLeft: 12px (reduced from 20px)
10. User/assistant icons distinguish request from response in tree

**Verification:** Chronological ordering works, subagent request/response visible, nesting reduced
