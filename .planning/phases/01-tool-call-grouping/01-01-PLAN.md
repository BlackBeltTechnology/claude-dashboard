- When a tool node is encountered:

- After reducing, post-process: unwrap single-item groups (count === 1) back to their original ToolNode
- Generate stable group IDs using `tool-group-${toolName}-${firstNode.id}`
- Group state should be 'active' if ANY contained node is 'active', otherwise use the first node's state
- Export the function as a named export

3. Add the toggleGroupExpansion action:
```typescript
toggleGroupExpansion: (groupId: string) => {
  set((state) => {
    const newSet = new Set(state.expandedGroups);
    if (newSet.has(groupId)) {
      newSet.delete(groupId);
    } else {
      newSet.add(groupId);
    }
    return { expandedGroups: newSet };
  });
},
```

4. Export a convenience atomic selector hook AFTER the store creation:
```typescript
export const useIsGroupExpanded = (groupId: string) =>
  useSessionStore((state) => state.expandedGroups.has(groupId));
```
