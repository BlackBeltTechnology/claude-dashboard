4. Create a `findToolNodeInSessions` helper function (defined outside the component or inside as a regular function). The algorithm is:
   ```typescript
   function findToolNodeInSessions(
     sessions: Session[],
     clickedRfNodeId: string
   ): { toolNode: ToolNode; sessionId: string } | null {
     for (const session of sessions) {
       // Search direct tool nodes
       for (const node of session.nodes) {
         if (node.type === 'tool' && createNodeId(session.id, node.id) === clickedRfNodeId) {
           return { toolNode: node, sessionId: session.id };
         }
       }
       // Recursively search subagent sessions
       for (const subagent of session.subagents) {
         const found = findToolNodeInSessions([subagent], clickedRfNodeId);
         if (found) return found;
       }
     }
     return null;
   }
   ```
   This works because `createNodeId` produces `${sessionId}-${nodeId}`, which is the exact same format used in `convertSessionToGraph` to create ReactFlow node IDs. By computing the same composite key and comparing with strict equality (`===`), we get a deterministic, non-fragile match.

5. Extend the `onNodeClick` handler to add an `else if (node.type === 'tool')` branch after the existing `tool-group` branch:

     if (found) {
