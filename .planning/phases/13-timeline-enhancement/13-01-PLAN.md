We need to ALSO create the new node types from the same user entries. Keep existing MessageNode creation unchanged (other code depends on it).

1. Add imports at top:
   ```typescript

   ```

2. Inside the `entry.role === 'user'` branch of buildNodes(), AFTER the existing MessageNode creation, add logic to create a UserPromptNode or ClearMarkerNode:

   a. Use the existing `extractReadablePrompt()` function to get the readable text from `entry.content`.

   b. Check if the extracted prompt is a /clear command using `isSkippableCommand()`.

   c. If it IS a /clear command: Create a ClearMarkerNode. Track a running `clearIndex` counter (start at 0, increment for each /clear found). The counter should be scoped to the buildNodes() call (local variable).
      ```typescript
      const clearNode: ClearMarkerNode = {
        id: `clear-${entry.uuid}`,
        type: 'clear-marker',
        parentId: entry.parentUuid,
        state,
        timestamp: entry.timestamp,
        clearIndex: clearCount++,
      };
      nodes.push(clearNode);
      ```

   d. If it is NOT a /clear command AND extractReadablePrompt returns text: Create a UserPromptNode.
      - Extract commandName from XML: check for `<command-name>` tag in `entry.content`
      - Extract commandMetadata: if content has XML tags, store the raw content as commandMetadata (truncated to 500 chars)
      - Set isCommand = true if commandName was extracted
      ```typescript
      const userPromptNode: UserPromptNode = {
        id: `prompt-${entry.uuid}`,
        type: 'user-prompt',
        parentId: entry.parentUuid,
        state,
        timestamp: entry.timestamp,
        promptText: extracted,
        commandName: commandNameMatch ? commandNameMatch[1].trim() : undefined,
        commandMetadata: hasXml ? entry.content.slice(0, 500) : undefined,
        isCommand: !!commandNameMatch,
      };
      nodes.push(userPromptNode);
      ```

   e. If extractReadablePrompt returns undefined (pure system XML with no user text), skip - do not create a UserPromptNode.

3. Initialize `let clearCount = 0;` at the top of buildNodes() before the loop.

4. For the commandName extraction, reuse the same regex pattern already used in extractReadablePrompt:
   ```typescript
   const commandNameMatch = entry.content?.match(/<command-name>\s*([^<]+?)\s*<\/command-name>/);
   const hasXml = entry.content ? entry.content.includes('<') : false;
   ```

IMPORTANT: Do NOT remove or modify the existing MessageNode creation for user messages. The new nodes are created IN ADDITION to MessageNodes. Other code (firstUserPrompt extraction, TreeView message rendering) depends on MessageNodes existing.

IMPORTANT: The `extractReadablePrompt` and `isSkippableCommand` functions are already defined in this file - reuse them directly, do not duplicate.
