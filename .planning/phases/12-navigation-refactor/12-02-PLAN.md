**GraphView.tsx - React to focusedNodeId changes:**
Import `useReactFlow` from `@xyflow/react`. Subscribe to `focusedNodeId` from the store.

Add a `useEffect` that watches `focusedNodeId`:
```typescript
const { fitView } = useReactFlow();
const focusedNodeId = useSessionStore((state) => state.focusedNodeId);

useEffect(() => {
  if (focusedNodeId) {
    // Small delay ensures React Flow layout is calculated
    const timer = setTimeout(() => {
      fitView({
        nodes: [{ id: focusedNodeId }],
        duration: 300,
        padding: 0.3,
      });
    }, 100);
    return () => clearTimeout(timer);
  }
}, [focusedNodeId, fitView]);
```

NOTE: `useReactFlow()` must be called inside a component that is a child of `<ReactFlowProvider>`. The GraphView component renders `<ReactFlow>` directly, so the `useReactFlow` hook needs to be in a child component. The simplest approach: extract the fitView logic into a small inner component `GraphFocusHandler` rendered as a child of `<ReactFlow>`:

```typescript
function GraphFocusHandler() {
  const { fitView } = useReactFlow();
  const focusedNodeId = useSessionStore((state) => state.focusedNodeId);

  useEffect(() => {
    if (focusedNodeId) {
      const timer = setTimeout(() => {
        fitView({
          nodes: [{ id: focusedNodeId }],
          duration: 300,
          padding: 0.3,
        });
      }, 100);
      return () => clearTimeout(timer);
    }
  }, [focusedNodeId, fitView]);

  return null;
}
```

Render `<GraphFocusHandler />` as a child of `<ReactFlow>` alongside Controls, MiniMap, Background.
