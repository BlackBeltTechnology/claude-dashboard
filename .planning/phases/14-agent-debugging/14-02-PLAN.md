Output: Visible subagent request/response in graph timeline and tree hierarchy.

       // Find the last assistant message as response

    **TreeView.tsx changes:**

    Currently when a subagent session is expanded in the tree view, it shows the subagent's child nodes (tools, messages, etc.) directly. The request (what the subagent was asked) and response (what it produced) are not visible as distinct entries.

    1. In the `renderNode` function, when rendering a Session that is a subagent (detected by `node.id.length < 20`), inject synthetic request and response entries at the top of the children list:

       ```typescript
       // Inside the session children rendering block (the `else` branch for Session nodes)
       // After the existing code that processes nodes and subagents:

       // For subagent sessions, prepend request and response entries
       if (node.id.length < 20) {
         const subagentChildren: React.ReactNode[] = [];

         // Find the SubagentNode in parent session to get prompt
         // We need the prompt from the subagent node data
         // Use firstUserPrompt as request text
         const requestText = node.firstUserPrompt || node.summary || '';
         if (requestText) {
           const requestNode: TreeNodeData = {
             id: `${node.id}-request`,
             type: 'message' as const,
             parentId: null,
             state: 'completed' as const,
             timestamp: node.createdAt,
             role: 'user' as const,
             content: requestText,
           };
           subagentChildren.push(renderNode(requestNode, depth + 1, nodeKey));
         }

         // Add existing children (processed tools, skills, etc.)
         subagentChildren.push(...sessionChildren);

         // Add response entry at the end
         const responseText = node.summary || '';
         if (responseText) {
           const responseNode: TreeNodeData = {
             id: `${node.id}-response`,
             type: 'message' as const,
             parentId: null,
             state: node.state,
             timestamp: node.lastActivity,
             role: 'assistant' as const,
             content: responseText,
           };
           subagentChildren.push(renderNode(responseNode, depth + 1, nodeKey));
         }

         childNodes = subagentChildren;
       }
       ```

    2. This creates user message (request) and assistant message (response) nodes that appear as the first and last children when a subagent session is expanded.

    **TreeNode.tsx changes:**

    3. Update `getNodeLabel` for message nodes that are part of subagent sessions. Currently message labels show content truncated to 50 chars. For subagent request/response, prefix with "Request: " or "Response: " based on role. Since we can't easily detect parent context in TreeNode, keep the existing label format — the user/assistant icons (person/robot) already differentiate request from response visually.

    4. No changes needed to TreeNode.tsx if the existing message rendering is sufficient. The user icon + message content for request, and robot icon + message content for response, provide clear visual differentiation.
