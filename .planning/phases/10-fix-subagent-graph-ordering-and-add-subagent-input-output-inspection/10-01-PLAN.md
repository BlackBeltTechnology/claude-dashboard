  <action>
Modify the fork-join pattern in `convertSessionToGraph` (the `if (session.subagents.length > 0)` block, approximately lines 256-455) to chain subagents sequentially rather than forking all from the same point.

**Current pattern (parallel -- the bug):**
```
forkPoint ---> SubagentA ---> JoinNode
           |-> SubagentB ---> JoinNode
           |-> SubagentC ---> JoinNode
```
All subagents get edges from `forkPointId`, so dagre places them at the same rank.

**New pattern (sequential -- the fix):**
```
forkPoint ---> SubagentA ---> [branch tail A] ---> seq-1 ---> SubagentB ---> [branch tail B] ---> seq-2 ---> SubagentC ---> [branch tail C] ---> JoinNode
```
Each subagent's branch tail connects to a sequencer node (type `'join-node'`, reusing the invisible JoinNode component), which then connects to the next subagent. Only the LAST subagent's branch tail connects to the final join node.

**Implementation steps:**

1. Keep the join node creation (it serves as the final convergence point for post-subagent continuation).

2. Replace the `for (const subagent of session.subagents)` loop with an indexed loop. Track a `chainPoint` variable that starts at `forkPointId`.

3. For each subagent at index `i`:
   - Create the subagent node (same as current code)
   - Create fork edge from `chainPoint` to the subagent node (NOT from `forkPointId` for all)
   - If expanded, render tools inline on the branch (same as current code)
   - Track `branchTailId` (same as current code -- either the last tool node or the subagent node itself)
   - If this is NOT the last subagent: create a sequencer node `${session.id}-seq-${i}` with type `'join-node'` and connect `branchTailId` to it. Set `chainPoint = seqNodeId` for the next iteration.
   - If this IS the last subagent: connect `branchTailId` to the `joinNodeId` (final convergence).

4. Keep `prevNodeId = joinNodeId` so the main timeline continues from the convergence point.

**Key details:**
- Sequencer nodes use `type: 'join-node' as any` (same pattern as the existing join node on line 268)
- Sequencer nodes use `data: { label: '' } as any` (same as join node on line 270)
- Sequencer nodes get dimensions from `NODE_DIMENSIONS['join-node']` (already exists: `{ width: 1, height: 1 }`)
- Do NOT use `hidden: true` on sequencer nodes (React Flow silently drops edges to hidden nodes -- see research pitfall #2)
- Edge styling for sequencer connections should use the same purple subagent style: `{ stroke: '#8b5cf6', strokeWidth: 1.5 }`
