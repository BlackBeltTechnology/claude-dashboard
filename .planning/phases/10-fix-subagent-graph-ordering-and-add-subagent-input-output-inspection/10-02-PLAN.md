**Part A: Widen selectedNodeData type in store (sessionStore.ts)**

The store's `selectedNodeData` is typed as `AnyNode | null`. The NodeDetail component accepts `TreeNodeData | null` which is `AnyNode | Session | ToolGroup`. For subagent inspection, we want to pass SubagentNode (an AnyNode), so the current type actually works. However, to also show the subagent's summary (which lives on the Session object), we need to find the SubagentNode from `session.nodes`.

No store type change needed -- `AnyNode | null` already covers SubagentNode.

**Part B: Wire subagent click in GraphView.tsx to also open detail panel**

In the `onNodeClick` handler (around line 173, the `else if (node.type === 'subagent')` branch), AFTER toggling expansion, also find the SubagentNode from the parent session's nodes and call `setSelectedNodeData`.

The SubagentNode entries in `session.nodes` are created by `buildNodes` in session-discovery.ts. Their IDs are `tool.id` (the tool_use UUID). The React Flow node ID for fork-join subagents is `createNodeId(session.id, subagent.id)` where `subagent.id` is the agent session ID (short hash from filename). These are DIFFERENT IDs.

To find the SubagentNode, search `session.nodes` for nodes where `node.type === 'subagent'` and `node.agentId` matches the subagent session ID (both are derived from the same agent hash). The `agentId` on SubagentNode is `tool.id.slice(-7)` and the subagent Session's `id` is the agent ID from the filename (e.g., `a8818a4`). These should match since both derive from the same 7-char agent hash.

Implementation in the subagent click handler:
```typescript
} else if (node.type === 'subagent') {
  // Toggle expansion (existing code)
  const subagentSessionId = findSubagentSessionId(node.id);
  if (subagentSessionId) {
    toggleSubagentExpansion(subagentSessionId);

    // Also open detail panel with the SubagentNode data
    // Search for the SubagentNode in parent session's nodes
    const findSubagentNode = (): AnyNode | null => {
      const searchSession = (session: Session): AnyNode | null => {
        // Check nodes for SubagentNode with matching agentId
        for (const n of session.nodes) {
          if (n.type === 'subagent' && n.agentId === subagentSessionId) {
            return n;
          }
        }
        // Check nested subagent sessions
        for (const sub of session.subagents) {
          const found = searchSession(sub);
          if (found) return found;
        }
        return null;
      };
      for (const session of sessions) {
        const found = searchSession(session);
        if (found) return found;
      }
      return null;
    };

    const subagentNode = findSubagentNode();
    if (subagentNode) {
      setSelectedNodeData(subagentNode);
    }
  }
}
```
