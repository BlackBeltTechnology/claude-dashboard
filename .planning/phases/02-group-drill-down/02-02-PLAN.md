  <action>
Create `client/src/components/GroupDrillDownPanel.tsx` -- a fixed-position right side panel that shows when a tool group is selected.

**Component structure:**
1. Read `selectedGroupId` and `setSelectedGroupId` from Zustand store
2. Read `sessions` from store to find the ToolGroup data matching selectedGroupId
3. Use `useRef` for the panel element, pass to `useClickOutside` for dismissal
4. Add Escape key handler via `useEffect`
5. Maintain local state: `selectedToolIndex: number | null` for which individual tool call is showing detail

**Finding the ToolGroup data:**
The `selectedGroupId` is a ToolGroup.id (format: `tool-group-${toolName}-${firstNodeId}`). To find the matching group:
- Import `groupConsecutiveToolCalls` from `../utils/groupingUtils`
- For each session (and recursively subagents), filter out message nodes and run `groupConsecutiveToolCalls` on the non-message nodes
- Find the item where `item.type === 'tool-group' && item.id === selectedGroupId`
- Extract the `nodes` array (array of ToolNode) from the ToolGroup

**Rendering:**
```
<>
  {/* Backdrop overlay - semi-transparent */}
  <div style={overlayStyle} />

  {/* Side panel */}
  <div ref={panelRef} style={panelStyle}>
    {/* Header with group name and close button */}
    <div style={headerStyle}>
      <h3>{toolName} ({count} calls)</h3>
      <button onClick={close}>X</button>
    </div>

    {/* Master list: tool calls */}
    <div style={listStyle}>
      {group.nodes.map((toolNode, index) => (
        <div
          key={toolNode.id}
          onClick={() => setSelectedToolIndex(index)}
          style={listItemStyle + highlight if selected}
        >
          <span>#{index + 1}</span>
          <span>{toolNode.toolName}</span>
          <span>{formatTimestamp(toolNode.timestamp)}</span>
          <span style={statusDotStyle(toolNode.state)} />
        </div>
      ))}
    </div>

    {/* Detail view: individual call details */}
    {selectedToolIndex !== null && (
      <div style={detailSectionStyle}>
        <div style={detailHeaderStyle}>
          <h4>Call #{selectedToolIndex + 1} Details</h4>
          <button onClick={() => setSelectedToolIndex(null)}>Back to list</button>
        </div>
        {/* Render tool input */}
        <div style={sectionStyle}>
          <div style={sectionTitleStyle}>Input</div>
          <pre style={codeStyle}>{JSON.stringify(toolNode.input, null, 2)}</pre>
        </div>
        {/* Render tool output if present */}
        {toolNode.output && (
          <div style={sectionStyle}>
            <div style={sectionTitleStyle}>Output</div>
            <pre style={codeStyle}>{toolNode.output}</pre>
          </div>
        )}
      </div>
    )}
  </div>
</>
```

**Inline styles (matching project conventions -- dark theme colors from existing components):**
- Overlay: `position: fixed, top/left/right/bottom: 0, backgroundColor: rgba(0,0,0,0.5), zIndex: 9998`
- Panel: `position: fixed, top: 0, right: 0, bottom: 0, width: 400px, backgroundColor: #16213e, zIndex: 9999, boxShadow: -4px 0 12px rgba(0,0,0,0.3), overflowY: auto, display: flex, flexDirection: column`
- Header: `display: flex, justifyContent: space-between, alignItems: center, padding: 16px, borderBottom: 1px solid #0f3460, flexShrink: 0`
- Close button: `background: none, border: 1px solid #0f3460, borderRadius: 4px, color: #888, cursor: pointer, padding: 4px 8px, fontSize: 14px`
- List items: `padding: 12px, marginBottom: 8px, backgroundColor: #1a1a2e, borderRadius: 6px, cursor: pointer, display: flex, alignItems: center, gap: 8px`
- Selected list item: `border: 1px solid #f59e0b` (tool color accent)
- Detail section: `padding: 16px, flex: 1, overflowY: auto`
- Code/pre blocks: `backgroundColor: #0f1729, borderRadius: 6px, padding: 12px, fontSize: 12px, fontFamily: monospace, color: #93c5fd, whiteSpace: pre-wrap, wordBreak: break-all, maxHeight: 300px, overflowY: auto`

**Close behavior:**
- Close button: `setSelectedGroupId(null)`
- Click outside (via useClickOutside hook): `setSelectedGroupId(null)` -- wrap the handler in `useCallback` to prevent stale closures
- Escape key: `useEffect` that adds keydown listener when `selectedGroupId` is truthy, calls `setSelectedGroupId(null)` on Escape, cleans up on unmount

**Important implementation details:**
- If `selectedGroupId` is null, return null (render nothing)
- Do NOT click the overlay div to close -- the useClickOutside hook handles this since the overlay is outside the panel ref. This is the correct behavior.
- Format timestamps using `new Date(timestamp).toLocaleTimeString()` for the list items
- Use named export `GroupDrillDownPanel` per project conventions
